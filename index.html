Seus documentos ficam com você

A coleta acontece no seu navegador, na aba do SIPAC. Os documentos não são enviados para o GitHub nem publicados neste site.

Por que um favorito?

O SIPAC não permite que outro site leia diretamente suas páginas. O favorito executa a consulta dentro do próprio SIPAC, sem servidor de coleta externo.

Escopo da consulta

A ferramenta foi feita para a consulta pública do SIPAC/UFBA em computadores. Ela registra os itens inacessíveis que aparecem na lista; itens ocultos não podem ser identificados.

Ferramenta independente · Código e página hospedados no GitHub
O favorito contém o código da ferramenta. Ao atualizar a ferramenta, adicione o favorito novamente.
